# JavaDevsProject
Задача 1: Тимлид (Ветка lead-foundation)
Цель: Заложить фундамент проекта, создать репозиторий, настроить сборку и определить контракт (интерфейсы), от которого будут отталкиваться остальные.

Что делаешь ты:

Создание репозитория: Создать пустой репозиторий на GitHub/GitLab, инициализировать .gitignore для Java (исключить target, .idea, *.log).
Настройка Maven: Написать pom.xml с зависимостями (JUnit для тестов) и базовой конфигурацией.
Модель данных: Реализовать класс Car и внутренний класс Builder.
Важно: Поля должны быть private final, конструктор приватный, методы билдера возвращают this. Никаких Lombok.
Контракт стратегии: Создать интерфейс SortStrategy<T>.
Метод: T[] sort(T[] array, Comparator<T> comparator).
Инициализация веток: Создать 4 дополнительные ветки (feat-sort, feat-io, feat-menu, feat-tests) от текущего состояния и отправить их на сервер.
Code Style: Прописать базовые правила именования в README.md.
