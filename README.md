# JavaDevsProject
Задача 4: Разработчик 4 (Ветка feat-menu)
Цель: Связать всё вместе в консольное приложение с циклом и меню.

Что делает участник:

Класс Main: Точка входа.
Цикл работы: Реализовать бесконечный цикл while(true). Внутри — вывод меню и обработка выбора.
Меню:
Выбор источника данных (Файл, Рандом, Вручную).
Ввод длины массива (если применимо).
Выбор алгоритма сортировки (Пузырь, Вставка, Выбор).
Выбор поля для сортировки (Мощность, Модель, Год).
Пункт «Выход» (завершает цикл через break).
Логика сборки: На основе выбора пользователя создавать нужные объекты (new FileFiller(), new BubbleSortStrategy() и т.д.) и передавать их в метод сортировки.
Вывод результата: Печатать исходный массив и отсортированный массив в консоль в читаемом формате.
Ключевые файлы:

app/Main.java
app/MenuPrinter.java (опционально, для красивого вывода)
